# CUDA Image Processing: Sobel Edge Detection

This project uses NVIDIA CUDA to process a high-resolution image on the GPU. It converts a color image into grayscale and then applies Sobel edge detection to highlight the edges and boundaries of objects.

The project uses **two separate CUDA kernels**, with Sobel edge detection being the main focus.

## How It Works

The image goes through two processing stages:

```text
      Input RGB Image
             |
             v
    Grayscale CUDA Kernel
             |
             v
       Grayscale Image
             |
             v
      Sobel CUDA Kernel
             |
             v
   Black & White Edge Image
```

### 1. Grayscale Conversion

The first CUDA kernel converts the original color image into grayscale.

Each pixel's color information is converted into a shade of gray. This simplifies the image and prepares it for edge detection.

### 2. Sobel Edge Detection

The second CUDA kernel applies the Sobel operator to the grayscale image to detect edges.

It examines changes in brightness between neighboring pixels to identify boundaries and important details in the image.

A threshold is used to produce a black-and-white output:

* **White pixels** represent detected edges.
* **Black pixels** represent areas where no edge was detected.

The result is a black-and-white image that highlights the shapes, outlines, and fine details of the original image.

## Implementation Details

* **Language:** C++
* **GPU Computing:** NVIDIA CUDA
* **Image Loading:** `stb_image`
* **Image Writing:** `stb_image_write`
* **Thread Block Size:** 32 � 32
* **CUDA Kernels:** Grayscale Conversion and Sobel Edge Detection

Each CUDA thread processes an individual image pixel. Using a grid of thread blocks allows the GPU to process many pixels in parallel.

CUDA events are used to measure the execution time of each kernel.

## Key Takeaway

This project explores **Sobel edge detection using CUDA** and demonstrates how edges and boundaries can be extracted from an image by detecting changes in brightness between neighboring pixels.
